## 0. 一句话

**让只会画平面草图的设计师，几分钟拿到能发工厂打样的 3D 珠宝模型。**

## 1. 创意来源：一个真实发生过的故事

作者（珠宝设计爱好者）曾为《三体·死神永生》设计过一件主题胸针《星环以外》：手绘草图上，剑与羽毛、雏菊与百合、镰刀与半幅桂冠分别以金、银、宝石紫的颜色语义呈现。

草图落地成实物的过程：

1. 委托专业建模师（小红书 @OneDayJeweler）沟通设计意图；
2. 建模师手工调整构图、专业 CAD 建模（数天）；
3. 打样确认后浇铸交付。

成品很美，但这段路花了近一周、以数百元计。而世界上有大量「会画图、不会建模」的独立设计师和小众爱好者，被卡在同一条路上：专业建模软件（Rhino/Blender）学习曲线以月计，外包沟通以天计。

**如果草图能直接变成可打样的模型呢？** 本项目就是对这个问题的回答，并以《星环以外》的真实案例作为复现基准。

## 2. 问题定义

| 用户 | 痛点 | 现有方案 | 缺陷 |
|:--|:--|:--|:--|
| 独立珠宝设计师 | 会画不会建模 | 自学 Rhino 等 | 数月学习曲线，珠宝曲面工艺另学 |
| 小众定制爱好者 | 一人一件不值得外包 | 外包建模师 | 数天周期、每轮收费、改稿难 |
| 小型工作室 | 打样前沟通成本高 | 反复邮件传图 | 无统一工程语言（尺寸/克重/水密性） |

关键洞察：**工厂打样真正需要的不是「完美模型」，而是「合格的工程输入」**——毫米级尺寸、实体克重估计、水密网格（能否出蜡模）。这三样恰恰是可程序化检验的几何问题。

## 3. 方案总览

```
手绘草图(手机拍照)
   │  ① 预处理：白平衡 / 颜色语义增强 / 方形居中
   ▼
Aholo Lux3D  img-to-3d  ──────────►  GLB 生成
   │  （双通道：API 直连 ／ 官网生成后拖入）
   ▼
一笔成珠平台（three.js，完全离线可用）
   ├─ ② 3D 工作台：转台 / 拖拽 / 棚拍布光
   ├─ ③ 尺寸标定：按目标佩戴尺寸等比缩放（mm）
   ├─ ④ 工厂交付单：
   │     · 三角形数 / 部件数
   │     · 实体体积（带符号四面体积分）
   │     · 925 银 / 18K 金 克重估计
   │     · 水密性初检：开放边界边计数（出蜡模前置条件）
   └─ ⑤ 一键导出：打样 STL（mm）+ 报告渲染图
```

## 4. 与 Aholo 技术栈的结合（评审维度 01）

**Lux3D 承担本项目最核心的环节：草图 → 3D。** 没有图生 3D 能力，本项目的「零建模门槛」无从谈起。

| 环节 | 使用方式 |
|:--|:--|
| img-to-3d 主通道 | 增强后的草图上传 Lux3D，生成带 PBR 材质的 GLB |
| 双通道容错 | API 直连（自动）与官网生成+拖入（联动）并存，零 key 也能跑完整演示，保证 Demo 稳定可运行 |
| 输入工程化 | 平台预处理管线把手机拍照的手绘稿转为 Lux3D 的优质输入：纸张白平衡、对比拉伸、颜色语义增强（金=黄、银=灰、石=紫）、1024 方形居中画布 |
| 后处理工程化 | Lux3D 输出（无绝对尺度的 GLB）被平台标定为毫米级工程模型，补上「AI 生成 → 工厂可用」的最后一公里 |

## 5. 工程化细节（评审维度 03 创新性 / 04 完成度）

- **颜色即语义**：草图上的色彩（金/银/紫）是设计师对材质的标注，预处理阶段定向增强这些色相，帮助生成模型保留多材质分区；
- **水密性初检**：量化顶点合并后统计边界边——每条边应恰好属于 2 个三角形；开放边数 >0 提示「出蜡模前需修补」，并用阈值分级（warn/bad）；
- **克重估计**：带符号四面体体积积分得到实体体积，乘以 925 银密度 10.36 g/cm³（K 金另列），给出工厂报价最关心的参数；
- **零依赖形态**：单文件网页 + 本地打包 three.js，双击即用、完全离线——评审与工厂都能 10 秒内跑起来。

诚实边界：AI 直出模型与设计师手工精修仍有差距（细节锐度、镶嵌位精度）；平台定位是「打样级」而非「量产免修级」，交付单上的水密性初检与尺寸标定正是为此设计的工程护栏。打样后工厂工程复核仍是必要环节。
