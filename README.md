## 解决什么问题

独立珠宝设计师的普遍处境：**会画图，不会建模**。把草图变成能交给工厂的 3D 模型，目前只有两条路——

| 现有路径 | 周期 | 门槛 |
|:--|:--|:--|
| 自学 Rhino / Blender + ZBrush 镶嵌件 | 数月起步 | 专业建模软件，珠宝曲面工艺另学 |
| 外包给建模师（沟通 → 建模 → 改稿 → 打样） | 数天~数周，每轮收费 | 沟通成本高，迭代慢 |

**一笔成珠**把这段路压缩到几分钟：上传草图 →（可选）AI 设计图增强 → Lux3D 生成 3D → 平台完成工程化与交互配置 → 浇铸化后处理 → 导出打样 STL 和交付单。设计师只管画。

## 真实案例基准

项目以设计师真实作品《星环以外》（《三体》主题珠宝：作者手绘草图、由专业建模师 @OneDayJeweler 建模落地）为复现基准——**同一份花环剑草图，建模师数天的手工精修 vs 平台数分钟的 AI 全流程**。草图、设计图与成品对照见 `sketches/` 与 `docs/` 目录。

> ⚠️ 区分声明：社交媒体上《星环以外》的 CAD 建模图为建模师受托制作的人工精修成果；本仓库产出的模型为 AI 生成 + 程序化工程化的独立版本，两者不可混同，报告中仅作人工基准对照。

## 完整功能一览

### ① AI 设计图增强（可选）
潦草草图不是理想的图生 3D 输入。平台集成 **GLM-4V-Flash**（视觉理解，免费）+ **CogView-4**（图像生成）：AI 读懂草图结构并转写专业设计指令，绘制成熟珠宝设计图后再进入 3D 生成——「潦草草图 + 一句话」达到专业设计图水准。

### ② 双通道 3D 生成
- **自动通道**：Lux3D API 直连（OUS 上传 → img-to-3d 任务 → 轮询 → GLB 自动载入），支持极速/精细引擎与面数选择
- **联动通道**：官网生成 GLB 后拖入，零 Key 也可完整体验

### ③ 交互式珠宝配置器（宜家式选购体验）
- **6 种金属**：18K 金 / 玫瑰金 / 925 银 / 铂金 / 镀黑铑 / 做旧银（PBR + 程序化棚拍环境光，含氧化包浆与拉丝表面），材质球实时预览
- **8 种切工 × 12 种宝石**：圆形明亮式 57 刻面 / 公主方 / 祖母绿阶梯切 / 阿舍尔 / 椭圆 / 梨形 / 马眼 / 枕形 × 钻石 / 红宝 / 蓝宝 / 黄蓝宝 / 紫蓝宝 / 紫尖晶 / 祖母绿 / 尖晶 / 海蓝宝 / 坦桑石 / 紫水晶 / 欧泊 / 珍珠（按折射率、密度做透射渲染，按体积×密度估算克拉）
- **点击即镶**：参数化宝石 + 包镶 / 爪镶金属连接结构，随整件换色并进 STL

### ④ 点击查看参数
- 主石：长宽厚、切割方式、估算克拉、折射率 / 硬度
- 戒圈：两点卡钳测量内直径，自动匹配港码 / 美码

### ⑤ 工程化交付单（实时刷新）
尺寸标定（mm）· 实体体积（带符号四面体积分）· 925 银 / 18K 金估重 · 水密性初检（能否直接出蜡模）· 开放边界边计数 · **悬浮部件检测**（顶点聚类并查集）

### ⑥ 浇铸化后处理（治 AI「线框感」的关键）
AI 对线稿的解读偏薄壳，直出常有「钢筋感」。内置 **Blender headless 浇铸管线**（`blender_cast.py`）：Solidify 0.75mm 铸造壁厚 → Voxel 0.28mm 重拓扑 → 铸面平滑 → 减面至打印规模——细壳变**实心铸造体积**，每个模型约 1 分钟。

## 三段式工作流（与专业软件的关系）

```
Lux3D 生成（AI 负责形）→ Sketch2Jewel 工程化+配置 → Blender/Rhino 精修（专业软件负责厂）→ 工厂
```

平台导出的 GLB/STL 可直接进入 Blender（内置自动化管线）或 Rhino 精修。AI 出形打样，设计师出精修——上下游而非替代关系。

## 技术栈

| 层 | 实现 |
|:--|:--|
| 3D 生成 | 群核 Aholo Lux3D `img-to-3d`（核心）/ GLB 导入通道 |
| AI 设计图增强 | 智谱 GLM-4V-Flash（识图）+ CogView-4（出图），可选 |
| 渲染 | three.js r128（本地打包，完全离线可演示）+ PMREM 程序化棚拍环境光 |
| 几何分析 | 量化顶点边界边检测 · 带符号四面体体积分 · 顶点聚类悬浮部件检测 |
| 参数化零件 | 8 切工 × 12 宝石程序化建模（frustum-stack 轮廓）+ 包镶 / 爪镶镶口生成 |
| 后处理 | Blender headless 浇铸管线（Solidify + Voxel Remesh） |
| 导出 | STLExporter（二进制 STL，mm 标定，含镶口） |
| 形态 | 零依赖单文件网页（`app/index.html` + `serve.py` 代理），离线可演示 |
