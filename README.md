## 解决什么问题

独立珠宝设计师的普遍处境：**会画图，不会建模**。把草图变成能交给工厂的 3D 模型，目前只有两条路——

| 现有路径 | 周期 | 门槛 |
|:--|:--|:--|
| 自学 Rhino / Blender + ZBrush 镶嵌件 | 数月起步 | 专业建模软件，珠宝曲面工艺另学 |
| 外包给建模师（沟通 → 建模 → 改稿 → 打样） | 数天~数周，每轮收费 | 沟通成本高，迭代慢 |

**一笔成珠**把这段路压缩到几分钟：上传草图 → Lux3D 生成 3D → 平台完成工程化（尺寸标定、体积/估重、水密性初检）→ 导出打样 STL 和交付单。设计师只管画。

## 真实案例基准

项目以设计师真实作品《星环以外》（《三体》主题胸针，作者手绘草图、由 OneDayJeweler 建模落地）为复现基准：**平台目标是在不依赖建模师的情况下，从同款草图产出可打样的模型**。草图与成品对照见 `reference/` 目录。

## 核心功能

- **草图即输入**：手机拍照的手绘图即可；颜色即语义（黄=金件、灰=银件、紫=宝石）
- **双通道生成**：Lux3D API 直连（自动），或官网生成 GLB 后拖入（联动），后者保证零 key 可用
- **3D 工作台**：转台预览、拖拽旋转、缩放，金银双色棚拍布光
- **工程化交付单**（右侧实时刷新）：
  - 尺寸标定：按目标佩戴尺寸（mm）等比缩放
  - 实体体积（散度定理计算）+ 925 银 / K 金估重
  - 可制造性初检：水密性（能否直接出蜡模）、开放边界边计数
- **一键导出**：打样 STL（单位 mm，可直接交 3D 打印蜡模）+ 报告渲染图

## 技术栈

| 层 | 实现 |
|:--|:--|
| 3D 生成 | 群核 Aholo Lux3D `img-to-3d`（核心）/ GLB 导入通道 |
| 渲染 | three.js r128（本地打包，完全离线可演示） |
| 几何分析 | BufferGeometry 遍历 + 量化顶点合并做边界边检测；带符号四面体体积分 |
| 导出 | STLExporter（二进制 STL，mm 标定） |
| 形态 | 零依赖单文件网页（`app/index.html`），双击即用 |

## 快速开始

```bash
# 方式一：直接双击 app/index.html（推荐，零依赖）
# 方式二：
cd app && python -m http.server 8787
# 打开 http://127.0.0.1:8787
```

没有 Lux3D 生成结果也能体验：点左侧「载入示例模型」走完整质检-导出流程。
